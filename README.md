# pbl-analysis

Planetary Boundary Layer (PBL) height estimation and analysis (R).

- `R/`       reusable functions (PBL algorithms, readers)
- `scripts/` analysis scripts
- `tests/`   tests
- `docs/`    design notes and specs
- `legacy/`  old draft scripts (reference only)
- `data/`    local data, not tracked by git
